# Hazari

A responsive scoreboard for four-player Hazari games. The Next.js application is in [`hazari-scoreboard`](./hazari-scoreboard).

## Run locally

```bash
cd hazari-scoreboard
npm install
npm run dev
```

Open http://localhost:3000 in your browser. See the [app README](./hazari-scoreboard/README.md) for scoring and deployment details.
